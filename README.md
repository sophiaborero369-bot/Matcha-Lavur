# Matcha Lavur

A browser-based storefront for Matcha Lavur drinks, sweets, powders, and merchandise.

## Run locally

Open `index.html` in a browser. The storefront supports product browsing, customer accounts, cart and checkout flows, order tracking, reviews, and customer messaging.

The owner dashboard is shown only when signed in with `matchalavur@gmail.com`. Account, order, inventory, and message data are stored in that browser's local storage.

## Prototype limitations

This is a front-end prototype, not a production e-commerce system. It has no server-side authentication, shared database, real payment processing, or real-time multi-device order synchronization. Do not enter real payment credentials or use it to process real customer orders. Production use requires a secure backend and payment provider.
